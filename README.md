# Student Placement Prediction using Machine Learning

This project predicts whether a student is likely to be placed based on academic performance, skills, and activities. A Machine Learning pipeline is built using Scikit-learn, and the model is deployed through an interactive Streamlit web application where users can input student details and get placement predictions.

---

## Features
- Streamlit web application
- Machine Learning pipeline
- Best model selection (Logistic Regression, Random Forest, SVM)
- Data preprocessing using ColumnTransformer
- Model saved using Joblib
- Interactive prediction interface

---

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Matplotlib
- Seaborn
- Joblib
